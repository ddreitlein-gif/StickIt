## Printable PDF guides

Download or print ready-made PDF guides: short Quick Start Guides for each role — Judges, Chief of Score, Event Secretary, Timekeeper, and Live Stream Crew — plus the Complete User Guide containing every topic in this help system as a single PDF.

Each quick start is two to four pages in plain language with diagrams, designed to print and hand out on event morning. Use View to open a PDF in your browser, or Download to save a copy.
